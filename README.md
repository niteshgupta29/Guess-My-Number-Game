# 🎯 Number Guessing Game

A simple Number Guessing Game built using HTML, CSS, and JavaScript.

## 🚀 Features

- 20 chances to guess the number
- Score decreases after every wrong guess
- High score tracking
- Responsive UI
- Restart game functionality

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🎮 How to Play

1. Enter a number.
2. Click **Check**.
3. Score decreases after every wrong guess.
4. Correct guess updates the high score.
5. Click **Again** to restart.
